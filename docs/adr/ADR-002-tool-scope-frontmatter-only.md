# ADR-002: 工具边界限定为 front matter 编辑

- 状态: Accepted
- 日期: 2026-07-27

## 上下文

博文 = front matter（结构化元数据） + 正文（自由 markdown）。需求要求"通过填表生成格式化的文件名、标题和 front matter"。正文编辑器是否内嵌会显著改变工具复杂度与工具边界。

## 决定

工具仅编辑 front matter 与文件名；正文交由外部编辑器处理。工具提供"在资源管理器中打开 `_posts/`"的快捷入口，但不在工具内编辑正文。新建博文时生成空正文占位或导入已有 markdown 正文（见 ADR-007）。

## 后果

- 正面：无需内置 markdown 编辑器/渲染器，复杂度大幅降低。
- 正面：聚焦工具核心价值——结构化 front matter 生成。
- 负面：用户需在外部编辑器与工具间切换；编辑 front matter 时正文被外部修改的冲突需处理（见 ADR-007 round-trip 策略）。
- 后续：v2 可考虑内置只读 markdown 预览（不编辑）。
