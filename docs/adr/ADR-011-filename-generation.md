# ADR-011: 文件名从 title/date 自动生成且始终跟随 title

- 状态: Accepted
- 日期: 2026-07-28

## 上下文

Chirpy 博文文件名格式为 `YYYY-MM-DD-TITLE.md`。工具需要把用户输入的 title 转换为文件名片段（slug），并决定是否允许用户手动覆盖文件名。此前需求允许手动修改文件名，但手动修改与 title 变更的关系未明确，容易引发不一致。

## 决定

- 文件名完全由 `date` 与 `title` 自动生成，格式为 `{yyyy-MM-dd}-{slug}.md`。
- `slug` 生成规则：
  - 中文字符原样保留。
  - 英文字母转为小写。
  - 空格转为 `-`。
  - 连续的空格或特殊符号压缩为单个 `-`。
  - 去除文件系统非法字符。
  - 去除首尾的 `-`。
- 文件名仅作为预览展示，**不提供给用户手动编辑**。
- 任何 `title` 变更都会实时重新生成文件名。

## 后果

- 正面：文件名与 front matter title 永远一致，不会出现“文件名与标题对不上”的混乱。
- 正面：减少一个可编辑字段，UI 更简单。
- 负面：用户无法在不改 title 的情况下自定义文件名（例如为了 SEO 缩写）。若需此能力，可在 v2 增加“slug 覆盖”高级选项。
