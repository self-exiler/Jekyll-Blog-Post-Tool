# ADR-003: 作者信息按项目隔离

- 状态: Accepted
- 日期: 2026-07-27

## 上下文

Chirpy 约定作者信息存于 `_data/authors.yml`，博文通过 `author: <author_id>` 或 `authors: [...]` 引用。需求提到"作者信息放在 _data/authors.yml 中，通过一组列表对作者信息进行管理，增删改"。作用域有两种选择：按项目隔离（每个博客独立一份）或全局共享（跨项目复用）。

## 决定

作者列表按项目隔离：工具仅读写当前博客项目的 `_data/authors.yml`，不维护全局作者库。Author 是 BlogProject 聚合内的实体，其生命周期与所属项目绑定。

## 后果

- 正面：模型简单，Author 的生命周期与 BlogProject 绑定，无跨项目同步问题。
- 正面：与 Chirpy 文件布局天然对齐。
- 负面：多博客项目间需重复录入作者（可接受，作者通常与博客绑定）。
- 注意：删除作者前需检查是否被 `_posts/` 中博文引用，提示用户处理引用。
