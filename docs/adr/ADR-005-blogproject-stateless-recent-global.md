# ADR-005: BlogProject 无状态，默认项目路径全局持久化

- 状态: Accepted
- 日期: 2026-07-28

## 上下文

需求曾要求“记忆最近打开的项目列表”。经过 grilling session 追问，用户认为最近列表增加了不必要的复杂度，希望工具启动后直接进入工作项目。需要明确 BlogProject 实体自身是否携带状态，以及项目路径如何记忆。

## 决定

- **BlogProject 是无状态的文件夹引用**：仅记录路径，不存项目级默认值。
- **不实现“最近项目列表”**：GUI 中不展示列表，启动时不维护多条历史记录。
- **仅持久化一个默认项目路径**：作为工具级全局状态存于 AppData JSON（见 ADR-009），启动时自动进入；路径失效时静默清空并回到项目选择页。
- 新建博文时表单字段为空（无预填默认值），用户每次手填。

## 后果

- 正面：BlogProject 值对象化，无持久化负担，无项目状态与文件系统不一致风险。
- 正面：全局仅记忆一个默认项目，启动路径最短，实现简单。
- 负面：多项目切换时需要重新选择文件夹，不如最近列表便捷（可接受，v1 优先简单）。
- 后续：若需默认值或多项目快捷切换，可扩展为“项目内 `.jekyll-tool.json` 覆盖全局默认”或恢复最近列表（v2 候选）。
