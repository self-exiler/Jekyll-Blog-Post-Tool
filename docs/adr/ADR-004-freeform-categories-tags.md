# ADR-004: 分类与标签自由输入

- 状态: Accepted
- 日期: 2026-07-27

## 上下文

Chirpy 规定 categories 最多 2 个、tags 0~无限。值的来源有三种模式：纯自由输入、受控词库（扫描已有博文，禁止新值）、受控词库 + 允许新增。

## 决定

categories 与 tags 均采用自由输入，工具不维护受控词库。Category 与 Tag 退化为字符串值对象，无独立聚合。

## 后果

- 正面：模型最简，无需词库管理与同步逻辑。
- 正面：UI 仅需文本输入控件（tags 可用 TokenizingTextBox）。
- 负面：可能出现大小写/拼写不一致（如 `Tutorial` vs `tutorial`）。
- 缓解：输入控件可提供"已有值自动补全"（扫描 `_posts/` 已有值作为建议，仅提示不强制），作为非约束性辅助，可在 v1.1 引入。
