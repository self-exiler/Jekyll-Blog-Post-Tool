## 4. 测试策略

### 4.1 分层策略

| 层 | 策略 | 说明 |
|----|------|------|
| Domain | 纯单元测试 | 无外部依赖，直接调用静态方法/构造函数 |
| Application | Stub 仓储单元测试 | 自定义 `StubPostRepository`/`StubAuthorRepository`，不触碰文件系统 |
| Infrastructure | 集成测试 | 使用 `Path.GetTempPath()` + GUID 临时目录，`IDisposable` 清理 |

### 4.2 测试约定

- 命名：`Method_Scenario_ExpectedBehavior`
- 一个测试方法只验证一个行为
- Stub 仓储以 `file sealed class` 限定在测试文件内
- 集成测试实现 `IDisposable`，`Dispose` 中清理临时目录
