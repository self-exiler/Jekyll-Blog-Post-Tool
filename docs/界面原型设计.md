# 界面原型设计说明

- 项目: Jekyll 博文 markdown 自动生成工具
- 版本: v1.5
- 日期: 2026-08-01
- 状态: Draft

## 1. 设计目标

界面遵循 Windows 11 设置（Windows Settings）的视觉风格，基于 WinUI 3 控件体系，追求：

- **简洁清晰**：减少视觉噪音，突出内容本身。
- **高效填表**：博文编辑字段多，布局以表单为主，分组明确。
- **原生体验**：用户无需学习成本，像在使用系统设置一样自然。
- **响应稳定**：信息密度适中，避免过度拥挤。

## 2. 设计语言

### 2.1 整体风格

- 采用 Windows 11 设计系统（WinUI 3）：圆角、柔和阴影、Mica/Acrylic 材质背景。
- 使用左侧导航栏（NavigationView）组织五大模块：**项目**、**作者**、**博文头信息**、**博文正文**、**高级功能**（v1.5：原"博文"页拆分为"博文头信息"与"博文正文"两个独立导航项）。
- 页面内容区采用“设置卡片（SettingsCard）”式分组，每组一个主题，右侧可放置操作控件。
- 默认支持浅色/深色主题，跟随系统；颜色全部取自 `Microsoft.UI.Xaml.Media` 主题资源，避免硬编码。

### 2.2 配色方案

| 用途 | 浅色主题 | 深色主题 | WinUI 主题资源 |
|------|----------|----------|----------------|
| 页面背景 | `#F3F3F3` | `#202020` | `ApplicationPageBackgroundThemeBrush` |
| 导航栏背景 | Mica 材质 | Mica 材质 | `NavigationViewDefaultPaneBackground` |
| 卡片背景 | `#FFFFFF` | `#2B2B2B` | `CardBackgroundFillColorDefaultBrush` |
| 卡片边框 | `#EBEBEB` | `#1D1D1D` | `CardStrokeColorDefaultBrush` |
| 主要文字 | `#1A1A1A` | `#FFFFFF` | `TextFillColorPrimaryBrush` |
| 次要文字 | `#5F5F5F` | `#A0A0A0` | `TextFillColorSecondaryBrush`
| 禁用/占位 | `#9CA3AF` | `#6B7280` | `TextFillColorTertiaryBrush` |
| 强调色 | 系统强调色 | 系统强调色 | `AccentFillColorDefaultBrush` |
| 错误提示 | `#D13438` | `#FF99A4` | `SystemFillColorCriticalBrush` |
| 成功/信息 | `#107C10` | `#6CCB5F` | `SystemFillColorSuccessBrush` |

> 所有颜色通过 WinUI 3 主题资源绑定，自动适配浅色/深色模式与系统强调色。

### 2.3 字体规范

| 用途 | 字体 | 字号 | 字重 | 行高 |
|------|------|------|------|------|
| 窗口标题/页面大标题 | Segoe UI Variable Display | 28px | SemiBold | 36px |
| 页面副标题/分组标题 | Segoe UI Variable Text | 20px | SemiBold | 28px |
| 卡片标题/设置项标题 | Segoe UI Variable Text | 14px | SemiBold | 20px |
| 正文/输入文字 | Segoe UI Variable Text | 14px | Regular | 20px |
| 说明文字/辅助提示 | Segoe UI Variable Text | 12px | Regular | 16px |
| 代码/预览 YAML | Cascadia Mono / Consolas | 13px | Regular | 20px |

> 中文环境下 Segoe UI Variable  fallback 至系统默认中文字体（Microsoft YaHei UI），保持清晰。

### 2.4 间距与尺寸

- 窗口默认尺寸：**1200 × 800 px**，最小尺寸 **900 × 600 px**。
- 导航栏宽度：**280 px**（左侧展开时）。
- 内容区内边距：**32 px**（左右），**24 px**（上下）。
- 卡片圆角：**8 px**。
- 卡片内边距：**16 px ~ 20 px**。
- 卡片之间间距：**12 px**。
- 表单字段垂直间距：**16 px**。
- 按钮默认高度：**32 px**；主操作按钮宽度根据内容自适应，最小 **80 px**。

## 3. 导航结构

左侧 NavigationView，五大入口：

```
┌────────────────────────────────────────────────────────────┐
│  ≡  Jekyll 博文工具                                        │
│  ────────────────────────────────────────────────────────  │
│  🗀  项目                                                   │
│  👤  作者                                                  │
│  📝  博文头信息                                             │
│  📄  博文正文                                               │
│  ⚙  高级功能                                               │
│                                                            │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

> 图标仅作示意，实际使用 WinUI 3 SymbolIcon / FontIcon。

- **项目**：管理项目路径，可在资源管理器或 VS Code 中打开项目。
- **作者**：管理当前项目的 `authors.yml`。
- **博文头信息**：新建或编辑博文 front matter（v1.5 由原"博文"页更名）。
- **博文正文**：编辑 markdown 正文、导入正文、插入图片（v1.5 新增）。
- **高级功能**：扩展工具集。v1.3 含"插入图片"，v1.4 新增"AI 设置"；v1.5 起图片插入移至"博文正文"页，仅保留"AI 设置"。
- 未选择项目时，**作者**、**博文头信息**、**博文正文**与**高级功能**入口禁用或显示提示。

## 4. 页面原型

### 4.1 项目页

功能：选择/切换博客项目，设置项目路径，可在资源管理器或 VS Code 中打开项目。

```
┌─────────────────────────────────────────────────────────────────────┐
│ 项目                                                                │
│ ─────────────────────────────────────────────────────────────────── │
│ ┌─────────────────────────────────────────────────────────────────┐ │
│ │ 项目路径                                                         │ │
│ │ C:\Users\dioha\OneDrive\文档\self-exiler.github.io               │ │
│ │                              [选择项目路径]  [资源管理器] [VS Code] │
│ └─────────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────┘
```

控件说明：

- 页面标题区不再放置操作按钮（v1.2：移除顶部“选择文件夹”按钮）。
- 项目路径使用 `SettingsCard`：左侧标题“项目路径”+ 路径文本，右侧操作区放置：
  - `Button` “选择项目路径”：唤起文件夹选择器。
  - `Button` “资源管理器”：以 `explorer.exe` 打开项目根目录。
  - `Button` “VS Code”：以 `code` 命令打开项目根目录；未安装时提示。
- 不再进行项目校验（v1.2：移除“项目校验”卡片及 `_posts/` 存在性检查；保存博文时自动创建缺失目录）。
- 路径文本过长时使用 `TextTrimming="CharacterEllipsis"`，鼠标悬停显示完整路径 Tooltip。
- 未选择项目时，“资源管理器”“VS Code”按钮禁用。

### 4.2 作者页

功能：增删改 `authors.yml` 中的作者。

布局采用左右分栏：左侧作者列表，右侧编辑表单。

```
┌─────────────────────────────────────────────────────────────────────┐
│ 作者                                                    [新增作者]  │
│ ─────────────────────────────────────────────────────────────────── │
│ ┌───────────────┐ ┌─────────────────────────────────────────────────┐ │
│ │ cotes         │ │ id *                                            │ │
│ │ Jane Doe      │ │ [cotes                            ]             │ │
│ │ ...           │ │                                                 │ │
│ │               │ │ name *                                          │ │
│ │               │ │ [Cotes                            ]             │ │
│ │               │ │                                                 │ │
│ │               │ │ twitter                                         │ │
│ │               │ │ [@cotes                           ]             │ │
│ │               │ │                                                 │ │
│ │               │ │ url                                             │ │
│ │               │ │ [https://...                      ]             │ │
│ │               │ │                                                 │ │
│ │               │ │ [保存]  [取消]  [删除]                          │ │
│ └───────────────┘ └─────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────┘
```

控件说明：

- 左侧 `ListView` 显示作者 id 与 name；选中某作者后右侧表单加载其数据。
- 右侧使用 `SettingsCard` 包裹表单，每个字段一行：标签 + `TextBox`。
- 必填字段（id、name）标签后加红色星号，保存时校验空值与 id 唯一性。
- 底部操作按钮：保存（主按钮）、取消、删除（危险样式，靠右）。
- 点击“新增作者”清空表单；删除时二次确认，不扫描博文引用。

### 4.3 博文头信息页（v1.5 由原"博文编辑页"更名）

功能：新建/编辑博文 front matter，实时预览文件名与 YAML。

布局采用左右分栏：左侧表单，右侧预览与操作。

```
┌─────────────────────────────────────────────────────────────────────┐
│ 博文                                          [新建博文] [打开已有博文]│
│ ─────────────────────────────────────────────────────────────────── │
│ ┌────────────────────────────────┐ ┌──────────────────────────────┐ │
│ │ 基本信息                        │ │ 文件名预览                   │ │
│ │ title *                        │ │ 2026-07-28-writing-a-new-post│ │
│ │ [Writing a New Post          ] │ │ .md                          │ │
│ │                                │ │                              │ │
│ │ date *                         │ │ front matter 预览            │ │
│ │ [2026-07-28] [14:10:00] [+08] │ │ ---                          │ │
│ │                                │ │ title: Writing a New Post    │ │
│ │ 分类                           │ │ date: 2026-07-28 14:10:00    │ │
│ │ 主分类 [Blogging          ]    │ │   +0800                      │ │
│ │ 子分类 [Tutorial          ]    │ │ categories: [Blogging,       │ │
│ │                                │ │   Tutorial]                  │ │
│ │ 标签                           │ │ tags: [writing, chirpy]      │ │
│ │ [writing, chirpy             ] │ │ authors: [cotes]             │ │
│ │ [AI 提取关键字]                │ │ description:                 │ │
│ │                                │ │   Short summary.             │ │
│ │ 作者                           │ │ ---                          │ │
│ │ ┌─────────────────────────┐    │ │                              │ │
│ │ │ cotes, admin        ▼ │    │ │                              │ │
│ │ └─────────────────────────┘    │ │                              │ │
│ │  ☑ cotes  ☑ admin  ☐ jane     │ │ [保存]                       │ │
│ │                                │ │                              │ │
│ │ 描述                           │ │                              │ │
│ │ [Short summary.              ] │ │                              │ │
│ │                                │ │                              │ │
│ └────────────────────────────────┘ └──────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────┘
```

控件说明：

- 页面标题右侧为 **"新建博文"** 与 **"打开已有博文"** 两个按钮（v1.2：原"打开博文"重命名为"打开已有博文"）；编辑已有博文时标题显示博文文件名。
- **表单区**使用 `SettingsExpander` 或 `SettingsCard` 分组：
  - `title`：`TextBox`，必填。
  - `date`：水平排列 `CalendarDatePicker` + `TimePicker` + `ComboBox`（时区偏移，默认系统时区）。
  - `categories`：两个 `TextBox`，分别标注"主分类""子分类"；主分类为空时子分类禁用（`HasCategory1`）。
  - `tags`：`TextBox`（用逗号分隔，原样保留大小写与中英文）。
  - `tags` 下方提供 **"AI 提取关键字"** 按钮（v1.4，FR-7.3）：点击后将当前正文发送给已配置的 AI，提炼最多 5 个关键字并**替换**已有标签（FR-7.4）；提取期间按钮禁用；未配置或正文为空时提示原因。
  - `authors`：**带复选框的下拉列表**（v1.2）。使用 `DropDownButton` + `Flyout` + `ListView` 内含 `CheckBox` 实现；按钮内容显示已选作者 id 列表或"无作者"占位；**作者可留空**（移除必填星号）；选项来自 `authors.yml`。
  - `description`：多行 `TextBox`（`AcceptsReturn="True"`），无最大长度限制。
- **预览区**：
  - 文件名预览使用等宽字体 `Cascadia Mono`，灰色背景卡片。
  - front matter YAML 预览使用 `TextBlock` + `Cascadia Mono` 字体，仅读，可选中复制。
- **操作区**：保存（主按钮，AccentButtonStyle）。（v1.5：导入正文按钮移至"博文正文"页）

### 4.4 打开已有博文入口

博文头信息/博文正文页无列表，通过以下两种方式打开：

1. **工具栏按钮**：页面标题右侧 **"打开已有博文"** 按钮（v1.2：原"打开博文"），点击弹出文件选择器，默认定位到当前项目 `_posts/`。
2. **拖放**：用户从资源管理器拖拽 `.md` 文件到工具窗口，校验文件属于当前项目 `_posts/` 后打开。

拖放无效文件时，在窗口底部显示 `InfoBar` 提示：

```
⚠ 只能打开当前项目 _posts/ 目录下的 .md 文件。
```

### 4.5 博文正文页（v1.5 新增）

功能：编辑 markdown 正文、从外部文件导入正文、插入图片到光标处、保存。

```
┌─────────────────────────────────────────────────────────────────────┐
│ 博文正文                                  [新建博文] [打开已有博文] [保存]│
│ ─────────────────────────────────────────────────────────────────── │
│ [导入正文...]  ☑ 替换而非追加                                        │
│                                                                     │
│ alt 文本  [留空则生成 ![](...)；图片将插入到正文光标处  ] [插入图片...] │
│ ─────────────────────────────────────────────────────────────────── │
│ 正文（Markdown）                                                    │
│ ┌─────────────────────────────────────────────────────────────────┐ │
│ │                                                                 │ │
│ │  在此编辑博文正文，或使用上方工具导入/插入内容...                 │ │
│ │                                                                 │ │
│ └─────────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────┘
```

控件说明：

- 页面标题右侧为 **"新建博文"**、"打开已有博文" 与 **"保存"**（主按钮）——与"博文头信息"页共享同一 `PostPageViewModel` 单例（`NavigationCacheMode=Required`，两页状态实时同步）。
- **导入正文行**：
  - **"导入正文..."** 按钮：选择外部 markdown 文件，剥离 front matter 后导入正文（FR-4.1~4.2）。
  - **"替换而非追加"** `CheckBox`：勾选时替换正文，否则追加到末尾（FR-4.3，默认追加）。
- **插入图片行**（v1.5，平铺不折叠）：
  - `alt 文本` 标签 + `TextBox`：留空则生成 `![](...)`；应用于本次所有图片（FR-4.10）。
  - **"插入图片..."** 按钮（AccentButtonStyle，`IsEnabled="{x:Bind CanInsertImages}"`）：`FileOpenPicker` 多选图片（jpg/jpeg/png/gif/webp/svg），复制到 `/assets/img/{slug}/`（文件名冲突自动追加 `-1`/`-2` 序号），markdown 引用插入到正文**光标处**；光标无效（无焦点/越界）时追加到末尾（FR-4.5~4.9）。
  - 可用条件 `CanInsertImages`（FR-4.11）：已选项目 且 slug 可确定——已保存博文用文件名 slug，未保存时用 title 即时生成（中文保留）；标题为空则禁用。
- **正文区**：`TextBox`（`Header="正文（Markdown）"`，`AcceptsReturn="True"`，`FontFamily="Cascadia Mono, Consolas"`，`TextWrapping="NoWrap"`，水平/垂直滚动），绑定 `VM.Body`（`TwoWay`）。
- 插入图片按钮的点击事件由 code-behind 传入当前光标位置（`BodyTextBox.SelectionStart`）。

## 6. 控件与状态规范

### 6.1 按钮

- 主操作：`Style="{StaticResource AccentButtonStyle}"`。
- 次操作：默认 `Button`。
- 危险操作：自定义样式，文字使用 `SystemFillColorCriticalBrush`。
- 禁用状态：使用 WinUI 默认禁用样式。

### 6.2 输入框

- 默认 `TextBox` / `ComboBox` / `DatePicker` 使用 WinUI 3 默认样式。
- 校验失败时边框变为红色，下方显示 `TextBlock` 错误信息：
  ```
  title 为必填项
  ```
- 必填字段标签后加 `*`（红色）。

### 6.3 提示信息

- 使用 `InfoBar` 显示非阻塞提示（如拖放错误、保存成功、路径失效）。
- 保存成功示例：
  ```
  ✅ 博文已保存到 _posts/2026-07-28-writing-a-new-post.md
  ```

### 6.4 加载/空状态

- 未选择项目时，作者页与博文头信息/博文正文页显示空状态：
  ```
  请先选择一个博客项目
  [前往项目设置]
  ```
- 加载作者列表时显示 `ProgressRing`。

## 7. 响应式与无障碍

- 窗口缩窄时，博文头信息页左右分栏变为上下堆叠（表单在上，预览在下）；博文正文页单列自适应，正文 TextBox 高度随窗口伸展。
- 所有交互控件支持键盘 Tab 聚焦，主操作支持 `Alt` 快捷键（如 `Alt+S` 保存）。
- 图标按钮配备 `AutomationProperties.Name`。
- 颜色对比度满足 WCAG AA 标准（WinUI 3 主题资源默认满足）。

## 8. 原型工具建议

- 可使用 Figma + Windows 11 UI Kit 绘制高保真原型。
- 开发阶段直接以 XAML 实现，参考本说明中的控件、布局与主题资源命名。
